# Практическая работа FastAPI

Простое API для книг. Исходный data.txt не предоставлен, поэтому в data.json добавлены три демонстрационные книги.

## Запуск в VS Code (Python 3.10+)

Откройте папку FastAPIPractice в VS Code. В терминале:

```powershell
python -m pip install uv
uv sync
uv run python src/fastapiprac/main.py
```

Готовый проект уже содержит pyproject.toml, поэтому uv init заново не нужен. uv sync создаёт виртуальное окружение .venv и устанавливает зависимости. При создании аналогичного проекта с нуля по методичке используются uv init и uv add fastapi pydantic uvicorn.

Откройте http://localhost:8000/docs. Остановка — Ctrl+C. Вторая документация — http://localhost:8000/redoc.

## Проверка через Swagger

Для каждого запроса раскройте блок, нажмите Try it out, заполните параметры и нажмите Execute.

1. GET /books — получить все книги.
2. GET /books/{book_id} — укажите 1: получить первую книгу.
3. POST /books — добавьте новую книгу:

```json
{
  "id": 4,
  "title": "Новая книга",
  "author": "Новый автор",
  "year": 2026,
  "genre": "Рассказ",
  "price": 500,
  "in_stock": true
}
```

4. PUT /books/{book_id} — укажите 4, передайте все поля книги с id 4, изменив, например, price на 600. Это полная замена данных, а не частичное обновление.
5. DELETE /books/{book_id} — укажите 4, чтобы удалить добавленную книгу.
6. GET /books — проверьте итоговый список. Можно перезапустить приложение: изменения сохраняются в JSON.

Ответы: 200 — успешно, 201 — создано, 400 — несовпадение ID при обновлении, 404 — книга отсутствует, 409 — повторный ID, 422 — неверный формат данных.

Не запускайте несколько экземпляров приложения одновременно: здесь учебное хранение в JSON, а не база данных.
